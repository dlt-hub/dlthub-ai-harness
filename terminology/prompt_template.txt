## Instructions

For each candidate, decide: **VIOLATION** or **ACCEPTABLE**.

A use is ACCEPTABLE when:
- The term appears in a definition or explanation of the preferred term (e.g., "a verified source — a pre-built connector" uses "connector" to define "verified source")
- The term appears in an enumeration, synonym list, or contrast (e.g., "REST API, HTTP API, web API" listing alternatives)
- The term is used in its general English sense, not the dlt-specific sense (e.g., "execute this command" where "execute" means run a shell command, not run a pipeline)
- The term is part of an external name, quote, or proper noun that cannot be changed

A use is a VIOLATION when:
- The deprecated term is used AS the primary term for the concept, where the preferred term should have been used instead
- The sentence would be more consistent with the rest of the documentation if the preferred term were used

## Output format

Respond with a JSON array. Each entry must have:
- "id": the candidate index (0-based)
- "verdict": "VIOLATION" or "ACCEPTABLE"
- "reason": one sentence explaining why
- "suggestion": if VIOLATION, the corrected text; if ACCEPTABLE, null
